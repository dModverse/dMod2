# Print or Pander Equation List

Print or Pander Equation List

## Usage

``` r
# S3 method for class 'eqnlist'
print(x, pander = FALSE, ...)
```

## Arguments

- x:

  object of class
  [eqnlist](https://dmodverse.github.io/dMod2/reference/eqnlist.md).

- pander:

  logical, use pander for output (R Markdown). Default `FALSE`.

- ...:

  not used.

## Value

`x`, invisibly.

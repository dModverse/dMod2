# Colorblind-Safe Seed Colors

Okabe-Ito palette, extended to twenty colorblind-safe colors. The first
eight are the Okabe-Ito colors.

## Usage

``` r
dMod_colors_cb
```

## Format

A character vector of 20 hex color codes.

# Summary of an Equation Vector

Prints, for each equation, the symbols it depends on.

## Usage

``` r
# S3 method for class 'eqnvec'
summary(object, ...)
```

## Arguments

- object:

  object of class
  [eqnvec](https://dmodverse.github.io/dMod2/reference/eqnvec.md).

- ...:

  not used.

## Value

`object`, invisibly.

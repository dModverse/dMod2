# Print a PEtab Problem

Print a PEtab Problem

## Usage

``` r
# S3 method for class 'petabproblem'
print(x, ...)
```

## Arguments

- x:

  A `petabproblem` returned by
  [`importPEtab()`](https://dmodverse.github.io/dMod2/reference/importPEtab.md).

- ...:

  Not used.

## Value

`x`, invisibly.

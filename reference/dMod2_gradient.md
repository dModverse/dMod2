# Continuous dMod2 Color Ramps

`dMod2_gradient` is the sequential house ramp, `dMod2_divergent` the
diverging one; `dMod2_gradient_cb` and `dMod2_divergent_cb` are their
colorblind-safe counterparts and the defaults of
[`scale_color_dMod2_c()`](https://dmodverse.github.io/dMod2/reference/scale_color_dMod2_c.md)
and
[`scale_color_dMod2_div()`](https://dmodverse.github.io/dMod2/reference/scale_color_dMod2_c.md).
See
[`dMod2_palettes()`](https://dmodverse.github.io/dMod2/reference/dMod2_palettes.md)
for the full set.

## Usage

``` r
dMod2_gradient

dMod2_gradient_cb

dMod2_divergent

dMod2_divergent_cb
```

## Format

Character vectors of hex color codes.
